# Storyline Skill 使用指南

> 2026.4.3: 正式发布 storyline.skill ver1.0! 欢迎大家使用并提出建议!

## 这是什么

一套帮你完成战略分析报告的 AI 研究助手。你负责定方向、给判断；AI 负责搜数据、做分析、写 storyline。最终交付物是一份可以直接用于制作演示文稿的结构化报告。

## 你需要做什么

**开始一个课题时**，告诉 AI 你要研究什么。可以是一句话的方向，也可以附上背景材料。AI 会整理成选题方案请你确认——确认前不会动手研究。

**研究过程中**，AI 会在几个关键节点找你：确认问题拆解、确认核心判断、确认终稿。其余时间 AI 自行推进，你不需要盯着。

**任何时候你都可以**：
- 追加材料或意见，AI 会自行整合
- 打断当前工作，要求换方向或回滚到之前的版本
- 直接修改项目目录里的底稿文件

**你不需要**：
- 给 AI 格式化的指令——口语化表达即可
- 逐步确认每个动作——AI 会自己判断什么该问你、什么该自己做
- 担心上下文丢失——所有过程都保存在本地底稿中

## 一个课题的典型流程

```
你给选题 → AI 拆解问题请你确认 → AI 独立研究
→ AI 形成核心判断请你确认 → AI 撰写完整 storyline
→ AI 自评并修复 → 你确认终稿 → 交付
```

你可以在任何环节插入反馈，不必等 AI 走完当前步骤。

## 项目文件说明

每个课题会在本地创建一个目录，结构如下：

| 文件/目录 | 内容 | 你会用到吗 |
|-----------|------|-----------|
| `00_输入/` | 你提供的原始材料 | 可以直接往里放文件 |
| `01_选题与议题树/` | 问题拆解、假设演进 | 想看 AI 怎么拆问题时翻一下 |
| `02_研究与数据/` | 搜集的数据和加工过程 | 想核实某个数据点时翻一下 |
| `03_storyline/` | storyline 各版本 | **主要关注这里** |
| `04_评估/` | AI 自评打分记录 | 想看质量评估细节时翻一下 |
| `progress.md` | 当前进度和待确认项 | **中断后回来先看这个** |
| `preferences.md` | 你的长期偏好记录 | 想修改 AI 对你习惯的理解时编辑它 |

你可以直接编辑任何文件。AI 每次启动时会检查是否有手动变更。

## AI 会记住你的偏好

AI 会从交互中学习你的习惯，比如你偏好什么论证结构、信任哪类数据源、讨厌什么样的表达方式。这些偏好记录在 `preferences.md` 中，跨课题复用。

- 你明确说"以后都这样做"时，AI 会直接记录
- 你反复修改同类问题时，AI 会识别为偏好信号并向你确认
- 新课题开始时，AI 会带入已有偏好，但会先确认是否仍适用

你也可以直接编辑 `preferences.md` 来调整。

## 质量保障

Storyline 完成后，AI 会用一套 7 维度评估框架自评，覆盖事实准确性、逻辑严密性、观点与事实分离、结构完整性、可执行性、边界感和量级感。存在严重问题（如编造数据、回避反面证据）时会触发红线一票否决。

评估结果保存在 `04_评估/` 目录下，你可以随时查看。

## 注意事项

- **AI 不替你做方向判断。** 选题、核心结论、最终拍板都是你的事。AI 会给建议，但不会擅自决定。
- **底稿不会被删除。** 即使某个假设被推翻、某段分析被替换，原始版本仍保留在目录中。
- **中断不影响进度。** 会话断了，下次开新会话时让 AI 读取项目目录即可继续。
- **交付物是 storyline，不是 PPT。** 如果需要生成演示文稿，将 storyline 交给 pptx skill 处理。
